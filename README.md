# Michael K. Davis — author website

The website for **Max Millhopper, Medical Detective™** and **Merlin's Knight School™**.

- Live site: https://calcaneus4.github.io/Max/
- To add books, links, pictures or translations, see **[HOW-TO-UPDATE.md](HOW-TO-UPDATE.md)**.

It is a plain static website (HTML, CSS and JavaScript, no build step), hosted free on GitHub Pages. Open `index.html` to preview it on your own computer.

## What's where

| Path | Contents |
|---|---|
| `data/books.js` | Series, books, characters, store and YouTube links (the file you edit most) |
| `data/lang/*.js` | Interface text and translations: English, Spanish, French, German, Italian, Japanese |
| `data/games.js` | Content for the four mini-games |
| `images/` | Covers, book art, character pictures, author photo (see `images/README.md`) |
| `index.html`, `series.html`, `book.html` | The home, series and book pages |
| `games.html`, `game-*.html` | Diagnose the Case, Merlin's Three Questions, Memory Match, Which Squire Are You? |
| `assets/` | Styles, scripts and the site icon |
