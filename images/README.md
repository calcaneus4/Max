# Pictures the site looks for

**Easiest way to add pictures:** upload them, with the names they have in the Google Drive
"Author Website" folders, into a folder called `incoming/` in this repository, then run
`python3 tools/import_images.py` (or ask Claude to). It renames, sorts and shrinks them into the
places listed below.

Any missing picture is replaced by a coloured title card, so add them whenever they're ready.
JPG, about 1600 px wide (covers about 1000 px tall).
